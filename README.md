# Cisco Packet Tracer - Complex Network Topology Lab

Welcome to this repository! This project presents a full simulation of a complex local area network (LAN) topology designed and configured using **Cisco Packet Tracer 9.0**.

---

##  Project Overview
This lab demonstrates the configuration and integration of various network devices to ensure seamless connectivity and proper routing across multiple subnets.

- **Simulation Tool:** Cisco Packet Tracer 9.0[span_2](start_span)[span_2](end_span)
